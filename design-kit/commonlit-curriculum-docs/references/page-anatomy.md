# Page anatomy: teacher and student copies

Built from real CommonLit 360 documents: "Button, Button" (reading lesson, Ed2.0), "Writing a Strong Claim" (writing lesson, Ed2.0), and "The Gift of the Magi" and "Planning Your Literary Analysis Essay" (Thematic Mini Unit, current template). Page setup in the current template: US Letter, portrait, 0.5 in side margins, 0.25 in top margin.

## 1. Running parts

| Part | Teacher copy | Student copy |
| --- | --- | --- |
| Header, page 1 | Large CommonLit logo + `Teacher Copy • <Unit name>` | Large logo + `Student Copy • <Unit name>` |
| Header, later pages | Small logo + `Teacher Copy • <Unit name>` | Small logo + `Student Copy • <Unit name>` |
| Footer text | `© CommonLit, Inc. <year>` | `Unless otherwise noted, this content is licensed under the CC BY-NC-SA 4.0 license.` ("CC BY-NC-SA 4.0" links to creativecommons.org/licenses/by-nc-sa/4.0/) |
| Page number | Right-aligned, `Page N` | Right-aligned, `Page N`, starting at 1 on the first student page |

How the template does it: the cover is its own **section** with "Different first page" turned on, so the cover gets the large logo. The lesson section starts its page numbering at 1. Use a **right-aligned tab stop** at the right margin for the page number. Don't push it right with a row of tabs or spaces: that breaks as soon as the footer text changes length.

## 2. Teacher cover page (Lesson Overview)

One page, teacher copy only. It ends with a section break or page break. Typical order:

1. **Title** (Title style): `Lesson Overview: <Lesson title>`.
2. Optional gray note: `(This page does not appear on the student copy.)`
3. **Where this lesson fits**: a row of boxes for the unit's lessons with `⬆ You are here! ⬆` under the current one.
4. **Knowledge focus / Skill focus** box: one or two sentences, standards at the end, e.g. `[RL.8.3, RL.8.6]`.
5. **Materials** box: `For You:` (this lesson handout, slide deck) / `For Students:` (`<Lesson title> (Student Copy)`, texts, reference sheets).
6. **Teacher Notes** / **Notes to Teachers**: bullets such as content notes, grouping guidance, and that `*` questions are optional.
7. **How to Facilitate** table (Blue-Gray box): one row per part with the modality, a one-line activity description, and minutes. A total time in the header row (`45 min.`, `~50–55 min.`).

Modality words are fixed vocabulary: **Whole class**, **Partner**, **Independent**, **Small group**, **Teacher led**.

## 3. Student part: opening

Everything from here on appears in both copies.

1. **Name / Class**: either a typed line, `Name: ____________   Class: ____________` (current template), or a two-by-two table (Ed2.0). This is the marker conversion tools use to find where the student part starts, so keep it as the first line after the cover.
2. **Title**: `<Lesson title>`. Ed2.0 teacher copies prefix it with `TEACHER COPY: `, which is dropped on the student copy. Newer templates use the plain title on both copies and rely on the header. The author goes on the next line for reading lessons.
3. **Teacher notice** (teacher copy only, own paragraph, blue): `*Answers in blue. To help us ensure assessment security, please do not post or circulate these answers online.*` (newer wording: `Answers are in blue. To ensure assessment security, please do not post answers online.`)
4. **Today's Goal(s)** box (writing lessons) or **About this Text** (reading lessons). A short paragraph addressed to the student ("You will…"), plus `Materials You'll Need` where relevant.
5. **Vocabulary** (reading lessons): `Let's pronounce these words together as a class:` then `Word [pro-nun-see-AY-shun]` entries.

## 4. Reading lesson body

**Reading the Text** with `Directions: Read the text, answering the During Reading Questions when prompted.`

The core is a **two-column table**:

| Left column (wide) | Right column (narrow) |
| --- | --- |
| Header row: `Whole Class Reading` / `Partner Reading` / `Independent Reading` | Header row: `During Reading Questions` |
| The text, with numbered paragraphs `[1]`, `[2]`, … and footnote numbers for glossed words | Questions placed **beside** the paragraphs they're about: `Paragraphs 1–3` then `Think and Share: <question>` |

- Each modality starts a new header row, so students and teachers can see where the reading mode changes.
- Questions line up with their paragraphs using empty lines in the right column. In the teacher copy, the answer bullets fill part of that space. The student copy must keep the same total height, or the rows shift and pages break differently.
- Keep each content row able to break across pages ("Allow row to overflow across pages" in Google Docs). Otherwise a tall row jumps to the next page and leaves the modality header stranded.
- Credit line under the text in gray: `"<Title>" by <Author> is in the public domain.` or the permission line given by the rights team. Never invent permission text.

**Question labels** (bold-ish Medium label, then the prompt):
- `Find Evidence:` highlight or underline details in the text.
- `Think and Share:` think, then share with a partner.
- `Turn and Talk:` discuss with a neighbor.
- `Write:` written response in the space below.
- `Poll the Class:` whole-class vote with options (`A. Yes`, `B. No`).

Lettered sequences inside a question box use `A.`, `B.`, `C.` (e.g. `A. Find Evidence:` then `B. Analyze:`). Optional questions start with `*`.

## 5. Writing lesson body

- Parts as section headings: `Part 1: <Name>` (or `PART 1: <Name>` in Ed2.0 headers), each followed by `Directions: <steps>. <N> minutes`.
- **Essay Prompt** box (Blue-Gray header row + prompt text + standard).
- Lists of requirements, organizers and outlines as tables. Left column: the row label (`Introduction`, `Body Paragraph 1`, `Idea about twist endings`). Right column: the space to write.
- **Checklist** box beside the writing space: `Checklist For Strong Claims:` / `Your central idea should:` with short bullets.
- Example boxes (`Example:` / `Prompt:` / model answer) are student-facing content. They stay black on both copies.

## 6. Discussion

- `Discussion` heading, directions, a **Question** box.
- **Discussion Sentence Starters** box (`What evidence from the text supports that idea?` …).
- Note boxes: `My ideas:` and `Ideas from the discussion:`.
- Student-Led Discussion pages use `My answer` / `My partner's answer` rows per question.

## 7. Independent practice

- Its own page, starting with the **Name / Class** line again.
- Heading `Independent Practice`, then `Directions: Answer the multiple choice questions for "<Title>." 5 minutes`.
- Multiple choice: numbered question with a standard at the end (`… in paragraph 74? [RL.4]`), and choices `A.`–`D.` as an auto-lettered list.
- Short response: a **Prompt** box with the prompt and standard, a reminder to break down the prompt, a checklist box, and a full-page answer box.
- Assessment security: in current materials, MCQ answers and the short-response exemplar for independent practice live in the online Answer Key, not in the teacher copy. The teacher copy shows the blue note: `Note: To ensure test security, the following assessment items are viewable only on commonlit.org for verified teacher accounts.`

## 8. Recurring components

| Component | Look | Notes |
| --- | --- | --- |
| Box / callout | Blue-Gray 200 fill `#E3EEF0`, 1pt `#C3DDE4` border, ~0.1 in padding | Goals, prompts, checklists, facilitation tables |
| Box header row | `#C3DDE4` fill, Open Sans Medium | "My Central Idea", "Essay Prompt" |
| Writing space | Empty table cell or empty lines, white | Height matches the expected answer length |
| Notes to Teacher | Orange-bordered box in some series | Teacher copy only; always in its own box so it can be deleted whole |
| Section divider | `***` centered | Between reading chunks |
| Timing | `5 minutes`, `10–15 minutes` at the end of directions | Student-facing; teacher-facing tables use `5 min.` |

## 9. Where answers go

| Question type | Teacher copy | Student copy |
| --- | --- | --- |
| Open response beside the text | Blue bullets under the question | Same number of empty lines |
| Answer box (table cell) | Blue text inside the box | Empty box, at least 3 lines tall |
| Fill-in after a label (`Central idea: …`) | Label black, answer blue on the same line | Label kept, answer removed, wrapped lines kept as space |
| Choose one of several | Correct option blue (often bold) | All options black, same weight |
| "Student responses will vary." | Blue, in the answer space | Removed |
| Poll / opinion | No answer | No change |
