# QA checklist

Run through this before handing a document to a person. For .docx files, `scripts/check_docx.py` covers the items marked ⚙.

## Both copies
- [ ] ⚙ Fonts are Open Sans (Light/Medium/Semibold), plus Crimson Pro or Source Code Pro only where the brand allows. No Open Sans Bold.
- [ ] ⚙ Text is black or ink. No accent-colored or yellow text. Links are link blue.
- [ ] Headings use real styles (Title, Heading 2). Sentence case, no ALL CAPS outside mono metadata.
- [ ] Every part has `Directions:` with an imperative and a time.
- [ ] Questions use the standard labels and point to paragraphs.
- [ ] Standards are real, or marked `[STANDARD]` and listed.
- [ ] No invented text, paragraph numbers or permission lines.
- [ ] Boxes use Blue-Gray 200 fill `#E3EEF0` with `#C3DDE4` border.
- [ ] ⚙ Page number right-aligned with a tab stop.
- [ ] No emoji, no decorative icons, no gradients.

## Teacher copy
- [ ] Cover page (Lesson Overview) present and ends with a page/section break.
- [ ] ⚙ Name/Class line or table is the first student-facing element.
- [ ] Header reads `Teacher Copy • <unit>` (and, in Ed2.0, the title reads `TEACHER COPY: <title>`).
- [ ] ⚙ Answers exactly `#0000FF`, and nothing else is that color.
- [ ] Correct choices marked by color only.
- [ ] Optional questions start with `*`.
- [ ] Teacher-only notes are each in their own paragraph or box.
- [ ] ⚙ Footer has `© CommonLit, Inc. <year>`.

## Student copy
- [ ] ⚙ No cover page. Starts with Name/Class.
- [ ] ⚙ No `#0000FF` anywhere, including on blank lines.
- [ ] ⚙ No "TEACHER COPY", "Answers in blue", test-security notes, or Notes to Teacher.
- [ ] ⚙ No `*` optional questions (unless your series keeps them).
- [ ] ⚙ No highlights.
- [ ] ⚙ Footer has the CC BY-NC-SA 4.0 line, with link, and no © line.
- [ ] ⚙ Page 1 uses a first-page header (large logo).
- [ ] Answer boxes a reasonable size. The short response box runs the length of the page.
- [ ] Page by page, questions sit on the same page as in the teacher copy, and no question is split across pages.
- [ ] File name says STUDENT COPY and keeps the lesson number and edition.
