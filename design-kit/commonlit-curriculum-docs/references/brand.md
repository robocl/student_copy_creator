# CommonLit brand for curriculum documents

Source: the CommonLit Design System (built from the CommonLit Brand Guidelines, 2025 rebrand), plus the conventions in current CommonLit 360 lesson templates. When the two disagree, **curriculum documents follow the lesson template**. Those differences are listed at the end.

## 1. Brand in one paragraph

Warm, library-inspired and calm: paper-and-ink neutrals, one bright action color, muted botanical accents. The design principles are **Joyful, Focused, Human, Inclusive**. "Form follows function; nothing is gratuitous." For a handout this means plenty of white space, a clear reading order, one idea per box, and nothing decorative that a student has to read around.

## 2. Color

| Role | Name | Hex | Use in handouts |
| --- | --- | --- | --- |
| Text | Ink 950 | `#1F1727` | All text (current templates use black `#000000`, which is fine). |
| Secondary text | Ink 800 / 700 | `#413A47` / `#57515C` | Captions, metadata. |
| Page | Paper / White | `#FFFEFA` / `#FFFFFF` | Page background is white in documents. |
| Box fill | Blue-Gray 200 | `#E3EEF0` | Goal boxes, "How to Facilitate" tables, checklists, prompts. |
| Box border / header fill | Blue-Gray 300 (template uses `#C3DDE4`) | `#C7DCE1` | Box borders, the header row of a box (e.g. "My Central Idea"). |
| Lines | Hairline | `#DDDBDA` | Table rules where a border is needed. |
| Accents | Mint 300 / Lavender 300 | `#CAD696` / `#C9A2CC` | Sparingly, as fills (unit color, a single callout). Never as text. |
| Action | School Bus Yellow | `#FFBF40` | Product and marketing CTAs. Not used for lesson content. |
| Link | Link blue | `#035FE6` | Hyperlinks only. |
| **Answers** | Answer blue | `#0000FF` | Teacher-copy answers only. See section 7. |

Rules from the brand guide:
- Type is ink. Never set text in yellow or an accent color, and never set text tone-on-tone (mint text on a mint box).
- Never combine accent colors in one element. One accent per page area is plenty.
- Never rely on color alone to carry meaning. A highlighted choice also has a label, an icon or a position that says what it is.
- No gradients, no glassy effects, no drop shadows in documents.

## 3. Type

| Role | Typeface | Weight | Size (current template) |
| --- | --- | --- | --- |
| Page title (lesson title, "Lesson Overview: …") | Open Sans | Medium | 20pt |
| Section heading ("Part 1: Breaking Down the Prompt") | Open Sans | Medium | 14pt |
| Box heading ("Skill Focus", "How to Facilitate") | Open Sans | Medium | 14pt |
| Body, directions, questions | Open Sans | Light | 11pt |
| Labels inside text ("Directions:", "Turn and talk:", "For You:") | Open Sans | Medium | same as the line |
| Table and box text, Name/Class line, notes | Open Sans | Light | 10–11pt |
| Display / marketing / reading titles in collateral | Crimson Pro | Semibold max | never below 20pt |
| Eyebrows, metadata, small descriptors | Source Code Pro | Medium | 9–10pt, ALL CAPS allowed |

Rules:
- **Never use Open Sans Bold (700).** Emphasis is Medium (500) or Semibold (600). In Google Docs, pick "Open Sans Medium" from the font menu rather than pressing Bold on Open Sans.
- **ALL CAPS only in Source Code Pro** (eyebrows and metadata). Headings, labels and buttons use sentence or title case.
- Don't over-emphasize. Bold, italics, underline, ALL CAPS and exclamation points should be rare.
- Book and work titles go in quotation marks in lesson text ("The Gift of the Magi"). In marketing collateral they can be Crimson Pro italic.
- Body text is never below 10pt in a handout (14px on screen).

Older Ed2.0 documents use Lato with teal header bars (`#447E86` with white text). That is the previous template. Don't copy it into new documents unless you are editing that older series and need to match it.

## 4. Voice and copy

The voice pillars are **Conversational, Relatable, Optimistic**: "teacher to teacher."

**Teacher-facing text** (cover page, notes):
- Second person "you", collective "we". Plain language, no jargon, contractions fine.
- Front-load the point. Verb-first where possible: "Guide students through the slide deck…"
- Respect teachers' time: short bullets, timing on every activity.

**Student-facing text** (the lesson itself):
- Directions are imperative and short: `Directions: Read the prompt. Then answer the question. 5 minutes`
- One task per sentence. Name the action, then the object.
- Questions name exactly where to look: "Paragraphs 26–34", "Reread the following excerpt from paragraph 36:".
- Use the CommonLit question labels consistently: **Find Evidence, Think and Share, Turn and Talk, Write, Poll the Class** (see `page-anatomy.md`).
- Standards in square brackets at the end of the question or skill line: `[RL.3]`, `[RL.8.3, RL.8.6]`, `[W.8.2]`.

**Everywhere:**
- "CommonLit" is one word; the curriculum is "CommonLit 360".
- Grade bands: "Grades 6–8" with an en dash.
- No emoji in anything external or student-facing.

## 5. Logo

- The logo is an image asset. **Never redraw it, retype it, recolor it, or approximate it** with a font or an icon.
- Curriculum documents use the logo in the **header**: the **large logo on page 1** and the **small logo on every later page**. In Google Docs this is done with "Different first page" headers.
- Placement: top-left in document headers. Avoid top-center and bottom-center.
- Clear space equals the height of the mark. Minimum height 16px digital, 0.5 in print for the glyph.
- If you don't have the logo file, leave the header logo to a template or a person, and say so. Don't fake one.

## 6. Accessibility (WCAG 2.1 AA)

- Text contrast at least 4.5:1 (3:1 for 24px+). Ink on white, ink on Blue-Gray 200, and ink on Mint/Lavender 200 all pass easily. Answer blue `#0000FF` on white is 8.6:1.
- Use real heading styles (Title, Heading 2) rather than big bold Normal text. Screen readers and the document outline depend on them.
- Every image that carries meaning needs alt text. Decorative images get none.
- Tables are for layout grids that students fill in. Give each a header row where it has columns.
- Never convey meaning by color alone. In teacher copies, answers are also *positioned* as answers (under the question, in the answer box), not just colored.

## 7. Where curriculum documents differ from marketing

| Topic | Brand guide (marketing/product) | Curriculum documents |
| --- | --- | --- |
| Colored text | Never | Answers in `#0000FF` on teacher copies, removed on student copies |
| Text color | Ink `#1F1727` | Black `#000000` is used in templates and is fine |
| Display serif | Crimson Pro for headlines | Not used in handouts; Open Sans Medium titles |
| Yellow | Primary action color | Not used in lesson content |
| Page background | Paper `#FFFEFA` | White (printing) |
| Footer | n/a | Teacher: `© CommonLit, Inc. <year>`; student: CC BY-NC-SA 4.0 line |
