Student Copy Creator

Turn a teacher copy into a student copy. Drop in the Word file and get the student version back in a few seconds.

  1. In the teacher copy Google Doc: File → Download → Microsoft Word (.docx)
  2. Drop the downloaded file below. It stays on your computer.
  3. Save the student copy, upload it to Drive, open it, then File → Save as Google Docs

Files are converted inside your browser. They are not uploaded or stored anywhere.

What you get back

Example
What it changes
  • Deletes the teacher cover page: everything before the Name / Class box.
  • Removes "TEACHER COPY:" from the title, and changes "Teacher Copy" to "Student Copy" in the header.
  • Changes the footer's "© CommonLit, Inc." line to the CC BY-NC-SA 4.0 line, with its link.
  • Erases blue answers and leaves blank lines for students to write in.
  • When the correct choice in a list is blue, keeps it and changes it to black.
  • Deletes the "Answers in blue" line, the blue test-security notes, "Notes to Teacher" boxes, and optional (*) questions.
  • Removes all highlights (including on footnote numbers) and comments.
  • Gives page 1 the large CommonLit logo and keeps the small logo on later pages.
  • Renames the file: removes "Copy of" and changes TEACHER to STUDENT.

It relies on the usual conventions: answers in the standard blue (#0000FF), and the student part starting with the Name / Class box. Based on "HOW TO: Making Student Copies for a 360 Unit".
